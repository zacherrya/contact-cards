# Contact cards

Static contact pages linked from the QR code on printed business cards.
Each folder is one person: an `index.html`, a `.vcf` with the photo embedded,
and the images the page uses.

Served by GitHub Pages. `robots.txt` and a `noindex` meta tag keep these pages
out of search results — they are meant to be reached from a card, not found.

Built from `contact-cards/` in the Claude Adobe workspace; `contact-cards/build/`
there holds the cropped portraits and the vCard generator.
